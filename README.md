# Del código fuente a la ejecución

Material didáctico sobre el proceso que sigue un programa desde su código fuente hasta su ejecución.

## Estructura del repositorio

```text
repositorio/
├── README.md
├── index.html
├── PROCESO.md
├── conversaciones-ia/
├── evidencias/
│   ├── fuentes.md
│   ├── skill-publica.md
│   └── prueba-skill-propia.md
└── skills/
    └── nombre-skill/
        └── SKILL.md
```

## Uso
- Abre `index.html` en el navegador para ver la página didáctica.
- Consulta `PROCESO.md` para un resumen estructurado.
